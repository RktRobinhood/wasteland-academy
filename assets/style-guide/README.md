# Wasteland Academy — Art Style Guide

These six reference sheets define the visual language for all art generated for this project.
Always provide them as context when generating new assets to prevent style drift.

## Style Sheets

| File | Content |
|------|---------|
| `style-01-world-overview.png` | World concept, color palette, Spark & Learner character overview, typography direction |
| `style-02-main-menu-home-hub.png` | UI layout, button states, player profile panel, HUD icons |
| `style-03-core-lesson-gameplay.png` | Lesson/combat screen layout, hint & feedback states, progress/reward panels |
| `style-04-world-map-travel.png` | World map, island nodes, vehicle (Wasteland Buggy), POI icons, travel rewards |
| `style-05-bazaar-inventory-crafting.png` | Bazaar/shop screens, inventory grid, crafting interface, item cards |
| `style-06-characters-dialogue-quests.png` | Full character roster (Learner, Spark, Gear Mira, Dax, Noma), expressions, quest cards |

## Key Design Tokens (from Sheet 1)

```
Scrap Teal    #22D3C5   (--col-teal)
Bazaar Magenta #FF3DA7  (--col-magenta)
Neon Mint     #9FF0E6   (--col-mint)
Rust Orange   #FAA261   (--col-rust)
Dust Yellow   #EACB74   (--col-dust)
Concrete Grey #9CA3AF   (--col-concrete)
Charcoal      #1F2937   (--col-bg)
```

Display font: **Scavenger** style — bold, hand-painted, rough, confident, imperfect.  
Body font: clean, readable, slightly distressed, tech-meets-handmade.

## Characters

- **Learner** — player character: curious, determined, hands-on, resourceful female scavenger
- **Spark** — AI companion robot: curious, helpful, a little sarcastic, always believes in you (WALL-E aesthetic, yellow patchwork body, blue glowing eyes)
- **Gear Mira** — Mechanic-Teacher NPC
- **Dax** — Trader-Engineer NPC  
- **Noma** — Map-Keeper NPC

## Prompt Notes for New Assets

- Black background, flat/minimal shading, bold outlines
- Same cyan + yellow accent colour palette across all assets
- Wasteland post-apocalyptic but hopeful — scrappy, colourful, community-built
- "Same math. Different world. Real problems. A brighter tomorrow."
