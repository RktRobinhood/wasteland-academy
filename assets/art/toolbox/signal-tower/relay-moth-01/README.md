# Relay Moth · static hover candidate

An original left-facing creature-family design for Signal Tower: soft linen wing surfaces, dark moth body, and salvaged insulators. Relay Moth is an art label, not enemy lore or an encounter assignment.

`exports/relay-moth.webp` is a 423 × 315 transparent WebP (40,068 bytes). The adjacent JSON describes a single 419 × 311 atlas frame with an approved-for-trial shoulder pivot at texture coordinates (158, 190). Unlike a grounded actor, this pivot intentionally anchors a hover, not the legs. Nominal rendered height 54 px; the proof compares 108 and 54 px over the locally audited Signal Tower plate. Use clean negative space if tried on busy backdrops. Isolated Godot 4.7.2 loaded the texture and validated the rect and pivot.

This is a still only. There are no wing animation frames or loop, no combat poses, no gameplay registration. The shoulder and wing silhouette leave room to produce separate motion later; don't fake a loop with an overall bob or call this an animated set. No externally sourced art.
