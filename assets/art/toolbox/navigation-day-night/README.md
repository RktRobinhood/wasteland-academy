# Overworld and zone boards: night art

The existing daytime maps and new matching moonlit alternatives, for the Overworld and all five syllabus zones. 12 day/night pairs across native portrait and landscape. The engine's regular portrait format is 1080×1920; 1920×1080 wide files are an additional approved-art-format candidate, not a claim that the current Web preset uses it. The separate [combat backdrop pack](../day-night/README.md) is already complete.

- Start with [index.json](index.json); map by `id` and `layout`. Each pair records the exact current main source and original-day checksum. Select only the final WebP or existing PNG. The day reference is byte-exact. Night art layers contain no hotspots, icons, controls or text.
- [Overworld, Radio Spires, Engine Core preview](preview-overworld-stats-calculus.jpg) · [Scrap Fields, Signal Tower, Dry Flats preview](preview-algebra-functions-geometry.jpg). Compare the two art phases to check navigational landmarks, not their exact pixels. The new images retain visible landmarks and spacing, but verify actual hotspot hits, touch zoom, pin cards and zoom centers before enabling the night backgrounds. Some unplaced ambient sky details change.
- Reuse the current map boards' markers and coordinates; never infer new routing or curriculum permissions from the art. When setting a local-time schedule, prefer local device time with no geolocation. Change only the background, preserve input and hover/focus state, and pin the currently viewed region through the transition.
- A brief dark tint dip (not a long bare dissolve where line work may be doubled) plus an instant reduced-motion swap should keep navigation stable. Do not preload all twelve textures; the visible location's matching pair is adequate. Ambient light pulses or mist are optional cosmetic overlays, never baked into controls or skill state.
- Files decoded in native Godot. This is an art-only branch handoff, not a deployed day/night clock or a validated runtime hotspot integration. Retain the current maps whenever a variant cannot be loaded or a viewport isn't supported.
