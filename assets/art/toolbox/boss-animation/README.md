# Animated named bosses

Boss animation handoff, art shelf only. In each named kit use `atlas.webp` and `sprite-frames.tres` from the same folder; move those files together. Godot's relative texture reference is deliberately portable. The atlas contains four hand-reviewed illustrated poses: neutral, blink, signature taunt and hit. Each clip uses deliberately held 2D poses and returns to its original anchor. These are three event clips per boss, not a walk cycle or an already implemented encounter.

- `idle` loops a short natural blink with a different hold per actor. `taunt` has a personal gesture and returns to neutral. `hit` is a brief readable non-graphic reaction and recovers. `clips.json` records frame UVs, playback seconds, story key, alpha bounds and the visual signature. Use the existing encounter signals to trigger these later; the art does not decide when or why a student loses.
- Reduced-motion option: show the stable neutral frame and any status text; do not repeatedly flash the hit pose or attach audio. Keep the learner's input and focus unaffected.
- Native checks: Godot 4 imported the WebP texture as real `AtlasTexture` frames; an actual `AnimatedSprite2D` advanced into gesture, reaction, recovery and blink. A second import from a moved directory confirmed the relative path. Art still needs a per-scene scale/placement trial.
- `preview.webp` is just a compact external animated review, not the import format. Do not use it at runtime, copy the preview or preload all bosses. Use the lossless atlas resource for the visible boss only; existing neutral portraits stay where they were.
