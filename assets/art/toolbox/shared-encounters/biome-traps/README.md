# Regional trap and terrain art

Three localized visual variants: Signal Tower's false mirror gate, Dry Flats' sandglass sinkhole, and Radio Spires' echo decoy beacon. Each is nonfunctional illustrated fiction, not a mechanic. See each manifest for its biome fit and visual cue. Prefer [the regional environment kit](../environment/README.md) for breakdown and obstruction art, and keep [shared humans](../raiders/) separate.

Each 640×420 transparent WebP was decoded in Godot and inspected on both exact lighting variants. The source retains original alpha. Draw-scale comparison thumbnails are not suggested map placements: position these only within an existing authored encounter and do not draw over map hotspots, text, answer controls or path anchors. Do not use silhouette artwork to infer a collision mask, answer, skill, or change to the existing encounter system. No integration is included.
