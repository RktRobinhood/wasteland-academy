# Five-biome creature library

**60 distinct creature families, twelve per biome.** This pass made and checked 55 original static cutouts, adding to five earlier art shelf families. The 20 expansion designs broaden the look of each particular place rather than recolouring the same body. Robots, creatures, biomechanical hybrids and flying forms have independent silhouettes. These are visual working labels, not gameplay rules, enemy stats, lore or quest assignments.

Pick a biome and species in the [complete roster](roster.json). Each new kit includes a left-facing static cutout, source master, and light/dark scale proof. For a test import use only `exports/idle.webp` with its measured footprint/hover anchor in `manifest.json`. Godot decoded the new static WebPs at 640×420 with transparency; test each selected sprite on the real scene in both light phases before release. Source masters and proofs aren't runtime assets.

Three of these families have separate optional [native flyer motion kits](../flyer-animation/README.md). The earlier Antenna Kite proof also remains available. The 60 count is families, not skins, animation frames, bosses or species in the game. Human raiders belong to a separate shared visual pool; keep environmental hazards, obstacles and breakdowns themed to their local biome. Neither category increases the creature count.

## Salvage-augmented round

Five new silhouettes visibly combine animal anatomy and junk machinery: Wreckback Bison, Relay Gibbon, Mirrorback Oryx, Induction Eel and Forge Rhino. Their original neighbors remain in the roster. Keep exposed joints and adaptive silhouettes visually grounded in each biome; favor re-used material over polished armor. These are static arena-art candidates, not gameplay assignments or animation rigs. The Eel is a fictional hover creature.
