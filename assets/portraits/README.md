Local Qwen Image 2.1 reference edits. Humans lock to the canonical roster. B0-LT uses the selected asymmetric factory-frame design with an amber monitor and crown tag. Screen tearing is a still; code supplies any flicker.

**New look (FAL-829, batch 3 of FAL-792):** all 16 portraits are redrawn in the FAL-792 ink-and-flat-colour look, in the same costume and colours as each character's new journey sheet (`assets/journey/cast/`). Framing, size, facing and the neutral-keeps-the-alpha rule are unchanged. The human moods are the neutral with only the face redrawn. B0-LT's moods change only the screen: a cream smile (pleased), an amber waveform (talk) and torn bars (glitch).
