# Privacy

- **No accounts.** Nobody signs up or logs in, and the game never asks for a name, an email address or a school.
- **Progress stays on the device.** It is saved in the browser the student plays in, and only there. Nobody else can see it. A student can export it as a code or a file and import it on another device; the game sends nothing, so it goes only where the student puts it.
- **No network calls beyond the site.** Everything the game uses comes from the site that serves it. Like any website, that host, GitHub Pages, sees ordinary page requests.
- **No telemetry.** An anonymous usage collector exists in the code but is not deployed, and turning it on needs the owner's approval first (#133).
