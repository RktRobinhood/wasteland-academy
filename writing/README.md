# Writing

Words the players read and hear: dialogue, hints, quest cards, lore, and the voice briefs for local voice design. Owned by Writer. The maths in a line belongs to Curriculum Author, so check with them before a teaching line ships.

Read [`../TONE.md`](../TONE.md) before you write anything. It says who we're writing for and what's underneath: IB survivors in the unknown after school, high school tropes and psychological damage.

| File | What it is |
|---|---|
| `voice-sheets.md` | One block per speaking character: wants, vocabulary, rhythm, tic and avoidance, praise and correction lines, samples. Write every line against it. |
| `voice-briefs.md` | Voice descriptions and audition scripts for Spark, Gear Mira and Noma, for VoxCPM2 on the shared GPU. |

## How text gets written here

- New characters get a voice sheet block first, accepted on a task, before any lines are written for them.
- Scenes, lore and editorials go through `sepia` (write for new pieces, review and refactor for drafts). Short text (hints, barks, quest cards, UI lines, audition lines) is drafted with `game-dialogue` and gets one `humanizer` pass. One anti-tell pass per piece.
- Every number in a line is computed before it ships.
- Lines never gender the player (see `voice-sheets.md`, conflict 1).

Written on FAL-332. The sample scene that tests these voices is a document on that task.
