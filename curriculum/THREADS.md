## Moving and stretching graphs (`transformations`)

Replacing x with x − a, or adding b to the output, moves every point by the same vector (a, b); multiplying stretches. The same rule is hiding in vertex form, a·sin(b(x + c)) + d, (ax + b)/(cx + d), the + C of integration and standardising z = (x − μ)/σ.

## Movement as a vector (`vectors`)

A vector says how far to move across and how far up. The translation vector of a graph, rise over run of a gradient, the shift in a·sin(b(x + c)) + d, displacement in kinematics and the step between two points in 3D are all the same object.
