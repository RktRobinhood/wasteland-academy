- **Functions:** 232 parts carry a 2.x tag, 171 of them as the main tag.
- A part normally goes to a type of its first (main) syllabus tag. A few parts follow the pattern instead: for example, twin-paper parts whose taggers listed the same two tags in opposite orders are kept together, and log-law steps inside an exponential model go with the model.

## Section A and Section B

| | Section A (questions 1 to 6) | Section B (questions 7 to 9) |
|---|---|---|
| Questions in the bank | 204 | 102 |
| Marks per question | 4 to 9, mean 5.8 | 12 to 18, mean 15.0 |
| Parts per question | 2.1 | 4.4 |
| Parts with a Functions main tag | 83 of 419 | 88 of 450 |

**Section A** questions are short and self-contained: one idea, worked in one to three parts, often a single 4 to 7 mark task with no lettered parts at all. A recipe for a Section A type generates one function and asks one or two things about it.

**Section B** questions are long chains of three to seven parts around one function or context. Early parts are cheap (write down an asymptote, evaluate at zero, read a vertex) and feed later ones; "show that" parts hand the student a result so they can carry on even if they went wrong; the last parts are worth the most and usually cross topics (a quadratic leads to a tangent, then an area; a log function leads to a discriminant). A Section B recipe must therefore generate one coherent set of numbers that keeps every later part clean, not each part on its own. The `chain` field of each Functions type records the usual order.

**Paper 1 versus Paper 2:** Paper 1 (no calculator) types need values that come out exact: integers, simple fractions, small surds, logs of exact powers. Paper 2 types expect technology and answers to 3 s.f., so a recipe should pick values that are *not* nice, to make the GDC route the natural one.

### fn-line-from-conditions

**Straight line from conditions, then use it.** Build a line from two points, a point and a gradient, a parallel or perpendicular condition, or its two intercepts; then use the line to find an unknown coordinate or an area.

- **Syllabus:** 2.1
- **Skills:** `SL2.1.gradient`, `SL2.1.equation-of-line`, `SL2.1.intercepts`, `SL2.1.parallel-perpendicular`
- **Where it appears:** P1 11, P2 1; Section A 9, B 3. Marks per part: usually 2 (1 to 4).
- **Usual chain:** midpoint of a segment (sometimes) → gradient of the segment → parallel or perpendicular gradient → equation of the new line through a given point → substitute a point to find an unknown coordinate, or use the line to find an area
- **Given:** coordinates, equation in y = mx + c or general form, words. **Asked:** A gradient, an equation in a stated form, or a coordinate found from the line. **Answer form:** exact, stated form (y = mx + c or ax + by + d = 0 with integer coefficients).
- **A recipe can randomise:** two integer points, or a point and a gradient p/q; parallel or perpendicular; the point the new line passes through; the form the answer must take; which coordinate is unknown in the follow-on part.
- **Limits that keep answers clean:** integer points and gradients with denominator at most 5; the given gradient is non-zero so the perpendicular gradient exists; when ax + by + d = 0 is asked, scale to integers with a > 0; intercepts must be non-zero when the line is built from its intercepts.
- **Game formats:** value, mcq, error-spot, match, method-pick, order-steps
- **Bank parts:** 12; also used as a step in 1 parts from other topics.

### fn-graph-table-composite-inverse

**Values, composites and inverse values read from a graph or a table.** A graph of f (or a table of f and g) is given; read a value, evaluate a composite, read an inverse value backwards, then solve an equation involving the inverse.

- **Syllabus:** 2.2, 2.5, 2.3
- **Skills:** `SL2.2.evaluate-notation`, `SL2.3.read-graph`, `SL2.5.composite-value`, `SL2.2.inverse-undo`, `SL2.5.inverse-domain-range`
- **Where it appears:** P1 8, P2 0; Section A 8, B 0. Marks per part: usually 2 (1 to 3).
- **Usual chain:** read f(a) from the graph or table → evaluate (f o f)(a) or (f o g)(a) by reading twice → read f^-1(b) by going from the y-axis back to x → domain of f^-1 is the range of f → solve f^-1(linear expression) = c by applying f to both sides
- **Given:** graph on a grid, table of values. **Asked:** Single values; one short equation solved by undoing f. **Answer form:** exact.
- **A recipe can randomise:** a piecewise-linear or simple one-to-one graph through grid points; a table of four to six x values with f(x) and g(x); which inputs are queried; the linear expression inside f^-1 in the last part.
- **Limits that keep answers clean:** every queried value lands on a grid point or a table entry; the inner output of a composite is itself an input the graph or table shows; f is one-to-one on the shown domain whenever an inverse is asked; the final equation's solution is an integer.
- **Game formats:** value, mcq, match, error-spot
- **Bank parts:** 8.

### fn-inverse-reflection

**Inverse as a reflection in y = x.** Sketch the inverse by reflecting the given graph in y = x, or use that symmetry to shortcut a calculation (equal areas, points on y = x).

- **Syllabus:** 2.2
- **Skills:** `SL2.2.inverse-undo`, `SL2.4.symmetry`
- **Where it appears:** P1 1, P2 1; Section A 1, B 1. Marks per part: 2.
- **Usual chain:** sketch f^-1 on the same axes by swapping key points → use the symmetry: intersections of f and f^-1 that lie on y = x, or an area doubled by symmetry
- **Given:** graph, equation. **Asked:** A sketch of the inverse, or a value found by using the y = x symmetry. **Answer form:** sketch, exact, 3 s.f..
- **A recipe can randomise:** the graph's endpoints and intercepts, which swap to (b, a); whether the follow-on uses the symmetry for an area or a distance.
- **Limits that keep answers clean:** f is one-to-one on its domain; key points on grid points so the swapped points are easy to check.
- **Game formats:** graph-pick, mcq, match, true-false-reason
- **Bank parts:** 2.

### fn-evaluate-function

**Evaluate a function or model at a given input.** Substitute into a given rule, usually a model in context: the value at time zero, at a stated input, or the y-intercept. Often the first part of a longer question.

- **Syllabus:** 2.2, 2.4

### fn-domain-range

**Domain and range, including restricted and transformed functions.** State a range from a vertex, an asymptote or endpoint values, including after a reflection or on a restricted domain; use a range to decide when a composite is defined.

- **Syllabus:** 2.2, 2.5, 2.6, 2.8, 2.11
- **Skills:** `SL2.2.domain`, `SL2.2.range`, `SL2.5.inverse-domain-range`
- **Where it appears:** P1 2, P2 2; Section A 3, B 1. Marks per part: usually 2 (1 to 4).
- **Usual chain:** find the vertex, asymptote or endpoint values → state the range → use it: the range of a transformed function, or the condition for g(f(x)) to exist
- **Given:** equation, equation with a restricted domain, graph. **Asked:** A range or domain, or a bound on a constant. **Answer form:** interval or inequality.
- **A recipe can randomise:** quadratic vertex; rational horizontal asymptote; restricted-domain endpoints; the transformation applied (reflection, translation).
- **Limits that keep answers clean:** endpoints are integers or simple fractions; decide deliberately whether each endpoint is included (the usual error); for composites, the range of the inner function must meet the domain of the outer one.
- **Game formats:** mcq, true-false-reason, error-spot, match
- **Bank parts:** 4.

### fn-sketch-gdc

**Sketch a graph from the GDC on a given domain.** Draw the graph of a given function on a stated domain from technology, labelling intercepts, turning points and endpoints.

- **Syllabus:** 2.3, 2.4

### fn-composite

**Form a composite, evaluate it, solve for a parameter.** Write (g o f)(x) for two given rules, evaluate it, or set it equal to a value and solve for an unknown constant.

- **Syllabus:** 2.5

### fn-inverse-algebraic

**Find an inverse algebraically, with its domain; self-inverse functions.** Swap and rearrange to find f^-1 for a linear, rational or root function, state its domain and range, show a function is its own inverse, or find a constant that makes it so.

- **Syllabus:** 2.5, 2.8, 2.2, 2.11
- **Skills:** `SL2.5.find-inverse`, `SL2.5.inverse-domain-range`, `SL2.8.rational-inverse`, `SL2.5.identity`
- **Where it appears:** P1 1, P2 4; Section A 1, B 4. Marks per part: usually 3 (2 to 8).
- **Usual chain:** (asymptotes of a rational function) → find f^-1(x) → state its domain and range → show f is self-inverse, or use that to find a constant → (link to reflections in the axes)
- **Given:** equation with a domain. **Asked:** The inverse expression, its domain or range, or a show-that. **Answer form:** exact expression, show that, interval.
- **A recipe can randomise:** f(x) = (ax + b)/(cx + d); f(x) = square root of (px + q); linear f; the restricted domain.
- **Limits that keep answers clean:** ad - bc is non-zero; a rational function is self-inverse exactly when d = -a; root functions need a stated domain so the inverse's domain is the original range.
- **Game formats:** mcq, error-spot, order-steps, method-pick, match
- **Bank parts:** 5.

### fn-exp-log-inverse-composite

**Exponential and log functions as inverses and composites.** Evaluate an exponential or log function, find its inverse by switching form, evaluate the inverse, simplify a composite of exp and log with log laws, and relate their graphs by transformations.

- **Syllabus:** 2.5, 2.9, 1.5, 1.7, 2.11
- **Skills:** `SL2.5.find-inverse`, `SL2.9.exp-log-inverse`, `SL1.5.exp-log-form`, `SL2.5.composite-expression`, `SL1.7.change-of-base`
- **Where it appears:** P1 11, P2 1; Section A 0, B 12. Marks per part: usually 3 (1 to 4).

- **Given:** equation. **Asked:** Values, the inverse rule, a simplified composite. **Answer form:** exact, simplified expression.

### fn-quadratic-features

- **Syllabus:** 2.6, 2.4
